# ⚙️ Módulo: ROS

## 📖 Sobre este Módulo
Este módulo concentra todo o desenvolvimento dos projetos no **ROS 2**, dentro dos containers do **Docker**, garantindo que o ambiente de compilação seja limpo, reprodutível e independente da máquina host.

## 📁 Estrutura de Pastas

O repositório possui uma única pasta principal (dado que as pastas build, install e log serão geradas automaticamente:

* 📁 `src`: Diretório principal onde todos os subtemas, pacotes e códigos de robótica são desenvolvidos.
