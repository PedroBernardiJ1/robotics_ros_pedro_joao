# ⚙️ Módulo: Docker

## 📖 Sobre este Módulo
Este módulo concentra toda a infraestrutura para configuração do container utilizando **Docker**, garantindo que o ambiente de compilação do **ROS 2** seja limpo, reprodutível e independente da máquina host.

## 📁 Estrutura de Pastas

O repositório é dividido em três áreas principais:

* 📄 `robot.dockerfile`: A receita de montagem da imagem com as dependências do ROS.
* 📁 `scripts`: Scripts de automação.
* 📁 `config`: Arquivos de configuração injetados no contêiner.
